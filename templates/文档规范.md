# 知径 · 文档规范

> 一切输出文档的统一标准。模板见本目录，工具生成与 AI 手写都遵循此规范。

## 总原则

1. **Markdown 通用**：终端可读，GitHub/Obsidian 直接渲染，不依赖任何工具；
2. **四件套结构**：`页眉元信息 → 分节正文 → 表格 → 页脚（状态/下一步）`；
3. **一份文档讲一件事**；标题最多三级（# → ## → ###）；列表统一用 `-`；
4. **数字只信工具**：一切数值取自 graph_ops 输出，与状态文件一致（不口算、不脑补）；
5. **时间戳格式统一**：`YYYY-MM-DD HH:MM`。

## 排版约定

| 元素 | 规范 | 示例 |
|---|---|---|
| 页眉 | `# 标题` + 元信息块，与正文用 `---` 分隔 | `# 学习报告 · Python 描述器` |
| 状态徽章 | 紧跟标题：`[进行中]` `[已毕业]` `[待处理]` `[已解答]` `[已入图谱]` | `# 复习记录 · 闭包 [已完成]` |
| 分节 | 带序号的 `##`，便于跳读 | `## 1. 概况` `## 2. 成绩单` |
| 数据表 | Markdown 表格；成绩单按分数**降序**；数字右对齐 | 见各模板 |
| 掌握度前缀 | 文档内 `✓`=已掌握 `◐`=半知 `○`=未知 | `✓类与实例(0.80)` |
| 事实分级 | 每条事实带 `[L1–L5]` + 出处；原文摘录用 `>` | `[L1]《托马斯微积分》2.1` |
| 进度条 | 20 格：`▓▓▓▓▓░░░░░░░░░░░░░░░ 24%` | 用于进度面板 |
| 分隔 | 大节之间用 `---` | 页眉后、附录前 |
| 页脚 | 收尾给"下一步/状态"，一行为宜 | `下一步: /teach 继续第 4 课` |

## 颜色语义（图与文档一致）

绿 = 已掌握；黄 = 半知；灰 = 未知。图上由 diagram-design 负责，文档内用 ✓/◐/○ 前缀。

## 通用页眉模板

```
# <文档名> · <主题>
- 时间: <YYYY-MM-DD HH:MM>
- 目标: <学习目标>   状态: [<状态>]
---
```
