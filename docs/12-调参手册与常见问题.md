# 12 · 调参手册与常见问题

## 1. 参数一览（改什么、在哪里改、有什么后果）

| 参数 | 位置 | 默认值 | 调大 → | 调小 → |
|---|---|---|---|---|
| λ（新知识点惩罚） | `graph.json → meta.lambda` | 3 | 更偏好走已知点/直连，路径保守 | 更敢引入新点，路径激进 |

## 2. 常见问题

| 现象 | 处理 |
|---|---|
| 路径"感觉不对" | `/doubt` 或 `/feel --r A B 新r` 修正关联度 → `/plan` 看变化。r 是系统与我的共同校准对象，不是写死的 |
| 一直回炉、门禁卡住 | 先判断：是真没会（继续练）还是题偏了（让 AI 换变式题）；长期卡住再考虑临时调门禁/步长 |
| 误打分/误修正/误导入 | `/undo` 回滚最近一次事件（恢复 m/间隔/r、移除导入节点） |
| teach-next 报"不可达" | 图谱不连通：回探寻补"桥梁"知识点，或 `/import` 导入相关材料 |
| 导入点太多 | 先不带 `--commit` 看候选清单，人工勾选后再入图 |
| 上下文失忆/会话断了 | 状态在文件里：直接说"继续学习" |
| 兴趣与必修冲突 | 两条线分开计费：/plan 时明确要"兴趣路线"还是"效率路线"，ω 调兴趣权重 |
| 成本 | 日常 deepseek-chat；只有 /plan 难决策、/demo 要讲透时才用 deepseek-reasoner |
| 图上的数字和我说的话对不上 | 数据必须来自 `graph_ops` 输出——让 AI 重跑对应子命令再画图（图也有幻觉，要防） |

## 3. 什么时候该动参数（判断标准）

- 校准误差（信心 vs 实际）持续 > 20% → 自查自欺，而非先怪系统；
- 同一门禁点反复卡 3 次以上 → 检查题目变式与 r 来源；
- 复习遗忘率高（3 天后再测 < 0.5）→ 下调 ef 增长、拟合个体 τ；
- 路径频繁被人工否决 → 系统性修正该主题的 r（材料依据不足时打"待确认"）。
