# 06 · 练习巩固与防自欺

## 1. 目标：把权重打下来——而且是真的打下来

权重减小的唯一正道是掌握度 m 上升（02 §3）。而 m 上升只认**生成式回忆**：合上材料能讲出来、能解变式题。**"再看一遍"不涨 m，"看懂了"不涨 m**——熟悉感不是掌握，这是防自欺的第一课。

## 2. 练习设计

1. **生成式回忆**：合上材料，默写/复述核心内容 → 与原文对比 → 评分（对/犹豫/错）；
2. **费曼检验**：讲给 AI 听；AI 追问"为什么"直到讲透；讲不下去的地方 = 没掌握的地方；
3. **变式迁移**：换场景、换问法、反向设问，防止模式匹配；
4. **交错练习**：混合多个知识点与间隔，由调度器安排，而不是集中刷同一题。

## 3. 间隔重复：权重的逐步减小

- **调度**：遗忘曲线 + 个体遗忘率 τ（由 08 的保留率反馈拟合）决定下次复习时机；通过 → 间隔拉长、m 升；失败 → 间隔缩短、m 降；
- **可视化**：路径图上我掌握的点变绿、边变亮、剩余总代价下降——"权重逐步减小"看得见（03 §5，原型第 5 节有演示）；
- **大节点门禁**：m ≥ 0.8 才放行下一个新点；不过关就回炉，不赶进度。

## 4. 防自欺机制清单

| 自欺形式 | 对策 |
|---|---|
| "我看懂了" | 生成式回忆测验，不许看材料 |
| "我本来就会" | 首次尝试成功率 + 犹豫时长记录（08 §2C）；蒙对不算全对 |
| "再刷几遍就会了" | 交错 + 变式，禁止原地重复同一题 |
| "我感觉会了" | 答题前自评信心 → 对照实际 → 校准误差进面板（08 §6） |
| 用原句复述 | 要求换自己的说法，禁止背诵式回答 |
| 侥幸做对 | 犹豫/蒙对 → m 只微升，并标记"待回炉" |
| 赶进度 | 门禁不放行；拖延率/跳过率入过程反馈（08 §2C） |
| 让 AI 放水 | AI 不迎合（01 P8）：我越自信，越出变式题验证 |

## 5. AI 的诚实角色

- 不因我的自信而跳过检验；不因我的沮丧而降低标准；
- 温和但坚定："你讲得不错，但反例这一步还没过去，我们换个角度再来"；
- 我的错误是**数据**不是罪过：每次错误都在校准图谱与调度，记录但不评判。

## 6. 深度与广度

- **深度**：反例、边界条件、证明梗概——由目标类型（理解/应试/创造）决定；
- **广度**：兴趣驱动的相邻话题，由兴趣向量（02 §4）与兴趣漂移反馈（08）导航；
- 两条线分开计费、分开调度，我随时调整比例。

## 7. 与校准面板的关系

"我以为会 vs 真会"的差距榜、信心 vs 实际正确率曲线，都在 `/calibrate` 面板里长期展示（08 §6）。防自欺不是靠自觉，是靠**每个答案前后都留下一行可对账的记录**。
