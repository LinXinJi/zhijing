# 03 · 最优学习路径算法

## 1. 问题形式化

**给定**
- 图 `G = (K, E)`：知识点为节点，每条边带**关联度** `r(a,b) ∈ (0,1]`；
- 每个点带**掌握度** `m(k) ∈ [0,1]`；**已知区** `S = { k | m(k) ≥ 0.8 }`；
- **目标点** `g`。

**步进代价**（02 §3 的权重公式）：

```
c(a→b) = ( 1 + λ·(1 − m_b) ) / r(a,b)        λ 默认 3
```

**问题**：求教学路径 `P = (s = x₀ → x₁ → … → xₖ = g)`，其中 `s ∈ S`，使总代价最小：

```
C(P) = Σ c(xᵢ₋₁ → xᵢ)
```

**性质**：`c > 0` 恒成立 ⇒ 正权图，**Dijkstra 精确可解**，无负权环问题。

**可选约束（支撑约束）**：每个新点 `xᵢ` 被引入时，它与"当时已掌握集合"的关联度之和 ≥ θ（默认要求至少有一个已掌握的直接邻居）。§4 的贪心教学顺序天然满足这一点。

## 2. 两种路径的权重对比：把直觉数学化

| 路径形态 | 例子 | 每步代价 | 总代价 |
|---|---|---|---|
| **已知点之间**（m_b≥0.8） | 斜率 → 切线（都学会后） | ≈ 0.7/r，**最便宜**：只付"连接"的力气 | 0.7/0.9 ≈ **0.78** |
| **新点直挂已知点** | 斜率 → 切线（切线未学，r=0.9） | (1+3×0.7)/0.9 ≈ 3.4，中等 | — |
| **连续两个新点中转** | 函数 → 极限 → 连续 → 导数 | 5.3 + 3.9 + 4.9，每一跳都付新点代价 | ≈ **14.2** |

三条候选路线到"导数"（数字由 `prototype/demo_path.py` 实际计算验证）：

- **直连**：斜率→导数，r 只有 0.45 → 3.7/0.45 ≈ **8.2**；
- **一个高关联中转**：斜率→切线→导数（r=0.9、0.9）→ 3.4 + 4.1 ≈ **7.6** ← 最优；
- **两个新点中转**：函数→极限→连续→导数 → **14.2**。

**结论**：算法自动偏爱"每一步都紧贴已知区、每跳关联都高"的路线；直连只有足够"顺"（r 够高）时才会赢；连续新点中转几乎总是输。这正是你说的"权衡出最优路径"：不是跳数最少（斜率→导数只有 1 跳），而是**关联度与掌握度权衡后的总代价最小**（2 跳但每跳都顺）。

## 3. 求解：多源 Dijkstra

1. 造超源 σ，连所有 `s ∈ S`，边权 0；
2. 从 σ 跑 Dijkstra 到 g；
3. 输出：最优路径、每步代价、每步的**"为什么"解释**（由边类型与 r 生成话术："先学切线，因为它和你会的斜率几乎是一回事，r=0.9；直连导数虽然只隔一跳，但关联只有 0.45，硬学反而更贵"）；
4. **Top-k 备选**：Yen 算法取前 k 条，或对 r 加噪声重跑 k 次去重；再按偏好排序：速度（总代价最小）/ 深度（强制加入反例、证明点）/ 兴趣（目标函数加兴趣项，见 §6）。

## 4. 教学顺序：贪心前沿扩张

Dijkstra 给出的是**静态**最优；真实教学中每教一个点 m 就变，图就变。所以"开始教学"阶段按贪心前沿逐步走：

```
已掌握 = S
while 目标 not in 已掌握:
    候选 = { 与已掌握直接相邻的未掌握点 }
    选 步进代价 c 最小 的候选 v（并满足支撑约束），记录步 (u→v)
    教 v（讲解 + 练习）→ m(v) 更新
    已掌握 += v
```

**性质**：
- 每一步引入的新点都直接挂在已知区上——"新点与我已知的点直接建立连接，无疑最好理解"的算法实现；
- 找不到候选（图不连通）→ 报告"中间缺一座桥"，回到探寻/计划补图谱；
- 与 Dijkstra 一致：理想情况下教学顺序 = 静态最优路径；若动态重算后出现更优支线则换路（§5）。

## 5. 动态重规划：权重如何"逐步减小"

每次练习后（08 反馈回流）：
1. **成绩反馈 → m 上升** → `(1−m_b)` 下降 → c 下降：同一条路径总代价持续下降，直到所有点都成"已知点之间"的纯连接价（≈0.7/r）——**"练习巩固逐步减小权重"的直接数学结果**；
2. **感受反馈 → r 修正** → 可能换锚点：原型第 6 节演示——我反馈"切线的斜率类比没听懂，但函数图像类比懂了"→ r(斜率,切线) 0.9→0.7 → 重算后最优路线自动从"斜率→切线→导数"切换为"函数图像→切线→导数"；
3. 新掌握的点可能打开更便宜的支线 → 重规划整条剩余路径。

**重算成本**：千级节点毫秒级，每次练习后实时重算毫无压力。

## 6. 兴趣与广度

- 目标函数加兴趣项：`C'(P) = C(P) − ω·Σ i(xᵢ)`——兴趣高的点"更愿意走"（ω 由我设定兴趣与效率的权重）；
- 广度探索：ε-greedy 偶尔推荐一条"略贵但有趣"的备选路线，防止学习路径上的路径依赖（与 01 §4 的多视角引擎呼应）。

## 7. 规模与性能

- 单主题图谱：数十～数千点，Dijkstra O((V+E)logV)，毫秒级；
- 跨主题大图谱（万级）：三级分层图（领域 → 章节 → 知识点），先算主题层路径再下钻，避免一次性铺开。
