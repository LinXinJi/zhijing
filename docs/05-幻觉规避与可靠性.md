# 05 · 幻觉规避与可靠性

## 1. 为什么在这个设定下幻觉最危险

唯一接口 + 高信任 = 它的错误我几乎不会去对照，会直接进脑，甚至进图谱、被 m 标成"已掌握"。所以可靠性不是附加功能，而是信任的基石（01 §3）：**信任只能建立在"可验证"上，而可验证的第一步是 AI 先自己验证自己。**

## 2. 五级事实分级：一切输出先定级

| 级别 | 含义 | 处理规则 |
|---|---|---|
| L1 确证 | 教科书/官方文档/标准定义 | 必须附来源（文件位置/链接），可引用原文 |
| L2 共识 | 学界主流观点 | 标注"主流"，给代表来源 |
| L3 争议 | 存在对立观点 | 必须给双方立场 + 各自来源，不做假平衡 |
| L4 前沿/推测 | 未定论、预印本、猜想 | 醒目标注"未定论/推测" |
| L5 未知 | 资料不足 / 不确定 | 直接说"我不知道，去查一下再答"，**不编** |

## 3. 技术防线

1. **检索优先（RAG）**：学习材料优先从可信知识库与**我的材料**（笔记 + 收集材料，接入管线见 09 §5）检索；LLM 只负责"用我的已知讲解"，不负责生产事实。
2. **生成约束**：公式 → 代入验算；代码 → 试运行；日期/人名/术语 → 查证；引用 → 逐条核对存在性（**禁止编造 DOI、页码、书名**）。
3. **来源可见**：每条关键事实后附 `[来源]`；讲完一个点附"延伸阅读"；在终端里 `/source` 一条命令随时出示原文片段。
4. **交叉验证**：L1/L2 关键事实至少 2 个独立来源；与我的已有材料冲突 → **指出冲突并讨论，绝不静默覆盖**。
5. **承认无知**："这个我不确定"是默认行为而不是丢脸行为——它是 L5 的合法输出。

## 4. 行为规范（给 AI 的规矩）

- 不确定即说；永不编造引用、数字、出处；
- 被质疑（`/doubt`）→ 复查来源 → 错了当面承认 → **写入纠错日志**（同一错误不再犯第二次）；
- 纠错日志是我的权益：我可以随时查看"它错过什么、改没改"；
- 讲解中的"直觉解释"若未经验证，必须标"这是类比，不是严格定义"。

## 5. 用户侧习惯（也教我一招防它）

- "请出示来源"随时可用，关键结论随手抽查；
- 关键事实隔几天换角度再问一次（既检验它的一致性，也检验我的记忆）；
- 对 L3/L4 内容默认存疑，不因语气自信就全收。

## 6. 度量与闭环

- 指标：幻觉率（被复核证伪的比例）、被质疑次数、纠错响应时长；
- 高错误率主题 → 该主题的材料与知识库降权、重建；
- 纠错日志周期性复盘，反馈进提示词与图谱来源质量分。

## 7. 与信任的关系（再说一遍）

承认局限与错误反而提升长期信任。开局就设预期："我也会错，所以我给自己标级别、给你留 `/doubt` 入口。"——我（用户）对系统的信任，本质上是对这套**自我检查机制**的信任，而不是对某一次回答的信任。
