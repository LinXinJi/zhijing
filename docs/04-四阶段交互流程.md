# 04 · 四阶段交互流程

## 总览：一个闭环

```
探寻 ──→ 计划 ──→ 演示 ──→ 教学
  ↑                          │
  └────── 反馈校准(08) · 动态重规划(03) ←──┘
```

每个阶段都有：**目标 / 输入 / 活动 / 输出（交付物）/ 完成标准（DoD）/ 防失败要点**。反馈收集贯穿全程，不只是教学阶段（08 §3）。

## 阶段一 探寻：摸清我已知的知识框架

- **目标**：画出"我已知的世界地图"，**从宽泛到具体**。
- **输入**：目标主题（如"导数"）、我可授权的已有材料。
- **活动**：
  1. **宽**（领域层）：这个主题我学过什么？多久前？什么场景下用的？
  2. **中**（主题地图）：列出相关子主题，我逐项打标：会 / 见过 / 不会。
  3. **细**（逐点探测）：对每个自称"会"的点，做**生成式回忆测试**（不给提示，让我讲出来）——区分"以为会"与"真会"。
  4. **材料导入**（授权后）：我的笔记与收集材料 → 本地索引 + 抽点、抽关联（09 §5）。
  5. **兴趣与基线**：兴趣评分、难度感受、动力、每日可投入时间——这是感受反馈的**基线档**（08 §3）。
- **关键准则**：探寻阶段说"不会"零成本，只记录不评判；"我以为会"是常态，用测试而非口头追问确认。
- **输出**：图谱快照 v0（已知区/半知区/未知区）、掌握度标定、兴趣向量、盲区与误解清单、负荷基线。
- **DoD**：目标主题的先修点全部打过标；标定可信（自评 vs 实测的校准误差已记录，08 §5）；我清楚自己"实际会什么"。
- **防失败**：我高估 → 生成式回忆兜底；我低估 → 测试通过即上调，绝不压进度。

## 阶段二 计划：推演最优学习路径

- **目标**：从已知区到目标的**最小权重路线** + 时间安排。
- **活动**：
  1. 跑路径算法（03）：最优路径 + Top-k 备选；
  2. 按偏好排序：速度 / 深度 / 兴趣；
  3. **协商**：我改目标、改节奏、砍分支，AI 实时重算并告诉我代价差异（"绕开极限要多付多少"）；
  4. 编排：里程碑、每周安排、练习与复习点、阶段门禁。
- **输出**：学习计划书 v1：路径图、每步代价与理由、预计课时、里程碑与门禁。
- **DoD**：我能复述"为什么先 A 后 B"；计划与我的时间/动力约束相容。
- **防失败**：计划过长 → 先出"最小可行路线"；兴趣与必修冲突 → 两条线分开计费，我知情选择。

## 阶段三 演示：展示完整的学习方案

- **目标**：让我**看懂并认可**这条路。
- **活动**：
  1. **可视化**：已知区绿色（我的锚点）、新点按教学顺序编号、边标 r 与代价、目标高亮（终端内 ASCII 渲染，可导出 Mermaid/HTML，见 09/10）；
  2. **讲解每一跳的逻辑**："先学切线，因为它和你会的斜率几乎是一回事（r=0.9）；直连导数虽然只隔一跳，但关联只有 0.45，硬学更贵"；
  3. **备选对比**：直连路线 / 中转路线 / 兴趣路线，各自总代价与风险；
  4. **成本与时间预估**；我可以改路线 → 实时重算；
  5. **预期管理**："这里会是全程最难的一跳，到时候我会这样帮你……"
- **输出**：冻结的计划 v2 + 留存路径图（教学阶段每走一步点亮一步）。
- **DoD**：我能向别人复述整条路线与理由；计划已确认。
- **防失败**：我只点头不追问 → AI 主动考一句"你说说，为什么先学切线？"；演示太花哨淹没重点 → 一屏一个结论。

## 阶段四 教学：讲解 · 连接 · 扩展 · 练习

**单课七步**（每步都有反馈收口，见 08）：

| 步 | 内容 | 时长 | 反馈收口 |
|---|---|---|---|
| 1 激活锚点 | 生成式回忆相关旧知识（小测验） | 2 min | 成绩 → m（08） |
| 2 讲解新点 | 只用已知点作锚，图形/类比/公式多表征，不引入第二个新概念 | 10 min | "这个类比懂了吗？" → r |
| 3 显式连接 | "导数是斜率的推广"——在图谱里真的建一条边给我看 | 5 min | 我自发类比 → 新增边 |
| 4 多视角 | 对立观点/历史/跨学科/反例（01 §4） | 5 min | "哪个角度最有启发？" |
| 5 兴趣扩展 | 深（为什么/反例/证明）与广（相邻话题地图），兴趣向量导航 | 选修 | 兴趣漂移 → i(k) |
| 6 练习 | 生成式回忆 + 变式题（06） | 10 min | 成绩 → m；30 秒感受收口 |
| 7 反思 | 元认知小结：今天新连了几条边？哪里还悬着？ | 3 min | 困惑清单 → 明日计划 |

- **阶段门禁**：新点 m ≥ 0.8 才进入下一个新点（防赶进度，06 §3）。
- **闭环**：成绩与感受反馈 → 校准参数（08）→ 权重变化 → 回到"计划"阶段动态重规划（03 §5）。

## 阶段间与整体

- 探寻产出图谱 v0，此后教学每节课都在更新它——**图谱是活的，系统和我一起长**；
- 任何阶段我都可以喊"停 / 换个讲法 / 我不信"，进入质疑与纠错流程（05 §4）；
- 阶段门禁与里程碑完成时做 5 分钟小复盘（动力、方法、兴趣）——感受反馈的重要采集点（08 §3）。
