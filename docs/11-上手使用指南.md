# 11 · 上手使用指南：到时候我怎么用

> 运行态一句话：**Pi agent 做"手"（终端、文件、命令、权限、审计），DeepSeek V4 Pro 做"脑"（讲解、规划、推理），本目录的文档与各学习目标目录的 `graph.json` 是它的操作手册与记忆。** 你不是打开一个"App"，而是在自己的终端里开一场和它一起学习的会话。

## 1. 一次性安装（10 分钟）

1. **装 Pi agent**：pi-mono（TypeScript 终端智能体工具包，官方仓库 [badlogic/pi-mono](https://github.com/badlogic/pi-mono)），按 README 安装（npm 全局安装）。
2. **接 DeepSeek**：官方给了接入指引 → [Integrate with Pi | DeepSeek API Docs](https://api-docs.deepseek.com/quick_start/agent_integrations/pi_mono/)，要点：`DEEPSEEK_API_KEY` + 模型 `deepseek-chat`（日常教学）/ `deepseek-reasoner`（规划与难题）。pi 支持自定义模型与 OpenAI 兼容 base_url，中文说明可参考 [pi-mono 自定义模型文档](https://founddream.github.io/pi-mono-master/zh/reference/models.html)。
3. **核实版本差异**：pi 更新较快，命令行参数与配置文件名以你安装版本的 [官方文档](https://deepwiki.com/badlogic/pi-mono/4.1-getting-started-and-cli-reference) 为准；本指南描述的是"怎么用"，不是"按哪个键"。

## 2. 目录布局（学习工作区 = 本项目）

```
F:\个人成长\AI共学系统\
  （上级目录）AGENTS.md       ← 知径协议：位于 F:\个人成长 根目录，pi 在任意子目录都会自动加载（若版本不支持，手动让它先读）
  （上级目录）背景知识.md      ← 总档案：AI 探寻出的背景知识（每次探寻后追加）
  skills/zhijing/SKILL.md    ← 教学技能卡：四阶段+命令的实现规范，pi 可随时调用
  学习记录\<目标>\graph.json  ← 图谱状态：唯一事实源（每个目标一个，init-goal 自动建）
  学习记录\<目标>\会话记录.md  ← 学习过程文本（每课结束追加摘要）
  学习记录\<目标>\图谱导出\    ← 规划图.svg / graduate 产物
  学习记录\<目标>\素材\        ← 该目标导入材料的索引/快照
  docs/                      ← 完整设计 01–11
  prototype/demo_path.py     ← 路径算法参考实现（可让 pi 直接运行对照）
  tools/graph_ops.py         ← 确定性计算（协议命令的数值内核，pi 用 run_command 调用）
```

**关键认知：记忆不在对话里，在文件里。** 会话断了、上下文满了都无所谓——新会话让 pi 先读 `AGENTS.md` + `学习记录\<目标>\graph.json`，它就"想起"一切。这是终端 agent 教学系统能长期跑下去的地基。

## 3. 首次初始化：一次探寻

```
> 在 F:\个人成长\AI共学系统 打开 pi 会话，说：

"读 AGENTS.md 和 skills/zhijing，按四阶段协议从『探寻』开始。
 学习目标：<你当前想学的主题>。先建/读 学习记录\<目标>\graph.json（init-goal），然后开始问我。"
```

（现成的完整开场白见 `pi/首次会话开场白.md`，可直接粘贴。）

pi 会按协议做三件事：宽（学过什么）→ 中（子主题打标：会/见过/不会）→ 细（对"会"的点做生成式回忆测试，区分"以为会"和"真会"），每一步把结果写回该目标的 `graph.json`。结束时的图谱快照就是你的 v0 地图。

## 4. 日常一次课（四阶段在终端里的样子）

```
我: 继续学"导数"，先看状态
pi: [已读 graph.json] 目标=导数(m=0.10)；已知区={斜率,函数,…}；
    最优路径: 斜率→切线→导数  总代价 7.56
    第 1 课: 切线。开始吗？

我: 开始
pi: [激活锚点·2分钟] 合上材料，用自己的话说"斜率"是什么？
我: 直线倾斜程度，纵差比横差
pi: 对。切线就是割线当两点无限靠近时的极限位置——它把你会的东西推广到曲线：
    直线上"处处相同的斜率"，在曲线上变成了"每个点的切线斜率"。[L1]《托马斯微积分》2.1
    [显式连接] 已建边 斜率→切线(r=0.9)：你笔记里写的"坡度"就是它的一维情形。

我: /source 切线
pi: [出示] 定义、出处、原文位置；事实等级 L1。

pi: 到练习了：/quiz 切线。先自评信心(0-100)，再答。
我: 信心 80。切线是割线的极限位置，切线斜率是该点瞬时变化率。
pi: [记录] m 0.30→0.48；3 天后复习。
    [收口·30秒] 今天哪里最卡？哪个类比没懂？负荷如何？
我: /feel 斜率类比有点绕；函数图像上的切线懂了；负荷正好。
pi: [校准] r(斜率,切线) 0.90→0.70，r(函数图像,切线) 0.80→0.85；
    重算路径: 最优改为 函数图像→切线→导数 (7.76)——下次换这个锚点讲。
```

每课 = 激活锚点 → 讲解（带来源）→ 显式连接 → 多视角 → 兴趣扩展 → 练习 → 感受收口（docs/04 七步）。**成绩决定 m 和进度，感受决定 r 和讲法**——这个分工是防自欺的根（docs/08）。

## 5. 命令表（协议命令，由 SKILL 实现，直接打字即可）

| 命令 | 作用 | 命令 | 作用 |
|---|---|---|---|
| `/status` | 当前图谱状态+进度 | `/plan` | 最优路径+备选对比 |
| `/demo` | 完整演示学习方案 | `/teach` | 按教学顺序开下一课 |
| `/quiz <点>` | 生成式回忆测验 | `/review` | 到期复习列表 |
| `/feel` | 30 秒感受收口 | `/calibrate` | 信心 vs 实际面板 |
| `/source <点>` | 出示来源 | `/doubt` | 质疑→复查→纠错日志 |
| `/init <目标>` | 新建学习目标目录（graph+会话记录+导出+素材） | `/status` | 图谱状态+进度 |
| `/import <路径>` | 导入笔记/材料（抽点→确认→入图） | `/graduate` | 终局知识图谱+过程报告 |
| `/graph` | 看图谱+导出 Mermaid | `/undo` | 回滚误打分/误修正/误导入 |
| `/progress` | 单目标进度面板 | 问"学到哪了" | 全部并行线总览 |

这些协议命令的**确定性部分**由 `tools/graph_ops.py` 执行（pi 调用它，LLM 只负责讲解与对话、把你说的话翻译成命令参数）。一套完整跑通的参考会话见 `学习记录\已经学完\` 下的 导数-参考会话 与 装饰器-参考会话。

## 6. 材料怎么进系统

`/import 路径`（你的笔记、`系统学习\` 下的资料、收集材料）：pi 解析 → 抽出候选知识点 → **逐条问我确认** → 入 `graph.json`，每个点锚定"出处文件+位置"。之后讲课引用材料时 `/source` 就能看到原文。我的笔记是最高信任来源，讲解优先锚定它（"你在 xxx.md 里写过……"）。

## 7. 学习完成：毕业

`/graduate` → `学习记录\<目标>\图谱导出\` 下生成三样东西：
1. `graduate.mmd` —— Mermaid 知识图谱：实线=教过的路（第几课），虚线=计划未走的路、感受反馈换的锚点、我自己发现的类比、半知区（如实标注，m 只信成绩）；
2. `学习报告.md` —— 结构化学习报告（概况/时间线/每个知识点一段"我是怎么学会的"/卡点与练习史）；
3. `graduate.json` —— 完整状态，可迁移。

贴进 Obsidian/GitHub 即渲染，或者继续让它长——图谱是可续写的活地图（docs/10）。

## 8. 注意事项（诚实清单）

- **上下文会满**：pi 的单次会话有长度限制。没关系——状态在文件里；每课结束让它把本节成果写回 `graph.json`，下次新开会话无缝接上。
- **它也会错**：关键结论坚持 `/source`；说"我不确定"是合法输出；`/doubt` 后它会复查并写纠错日志（docs/05）。
- **隐私**：全部本地文件，`graph.json` 是你的思维地图，不要上传公开仓库。
- **版本漂移**：pi 与 DeepSeek 接口偶有变动，安装后先跑通一句"你好+读 AGENTS.md"，再开始正式学习。
- **先从真主题开始**：第一次用建议选 `系统学习/` 里你最想推进的一个（比如 Python 装饰器），走完整四个阶段；跑通一次，整个系统的用法你就全懂了。
