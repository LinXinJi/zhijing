# 01 · 核心理念与信任设计

## 1. 定位：AI 不是工具，是头脑的"唯一接口"

所有想学的内容、所有零散的信息，都从这一个入口进出。这个定位带来两个巨大好处，也带来两个必须正视的风险：

**好处**
1. **知识状态集中管理**。因为所有学习都经过它，它永远持有一份最新的"我知道什么、会到什么程度"的地图（见 02 知识图谱）。换任何其他工具，这份地图都会断裂。
2. **熟悉度复利**。它记得我的语言风格、我举过的例子、我栽过的坑，每次讲解都从"我的已知"出发——信息接收阻力最小，理解最快。

**风险**
1. **单点依赖**：入口唯一 ⇒ 它出错时没有第二通道对照。
2. **信息茧房反噬**：入口唯一 ⇒ 它若不主动提供对立视角，我会越来越偏。

对策贯穿全部文档：可靠性层（05）负责"它的话可验证"，多视角引擎（本节 §4）负责"它主动给我另一面"。

## 2. 熟悉性设计：如何让我"越来越信"

熟悉感不是寒暄话术，是**记忆 + 一致性 + 用我的语言**：

| 机制 | 具体做法 |
|---|---|
| 长期记忆 | 三份档案：① 用户画像（称呼、表达风格、作息、学习偏好）；② 知识图谱（已知点、掌握度、最近练习时间）；③ 对话史（举过的例子、共识过的说法） |
| 一致性 | 稳定的"人格"：解释风格、示例偏好、玩笑分寸、追问方式始终如一；不忽冷忽热 |
| 用我的语言 | 讲解永远优先引用**我自己**说过的话、用过的例子："还记得你用温度计类比过函数吗……" |
| 渐进适应 | 随着掌握度上升，术语层次自动提高；新概念永远先翻译成"我的词库"里的词 |
| 主动熟悉 | 每次课前用 30 秒回顾"上次我们学到哪、你当时卡在哪"——比任何仪式都更能建立"它懂我"的感觉 |

## 3. 信任设计：信任 = 可验证，而不是权威感

一个关键判断：**在唯一接口的设定下，信任是系统最重要的资产，而幻觉（05）是对这份资产最致命的打击。** 因此信任不能靠"显得博学"建立，只能靠"可以被验证"建立：

**信任公式（设计准则）**

```
信任 ∝ 准确率 × 透明度 × 承认无知的意愿 × 一致性
        ─────────────────────────────────────────────
        夸大程度 × 模糊程度 × 被纠正后的抵赖
```

由此推出五条铁律：
1. **不确定即明说**。"这个我不确定"比编一个答案更能积累信任。
2. **可溯源**。每条关键事实都能点开来源（教材章节/论文/官方文档）；点不开的，明确标注"据我所知，建议核实"。
3. **说错就认**。被指出错误 → 复查来源 → 当面承认 → 写进纠错日志，同一错误不再犯第二次。
4. **永不迎合**。不因为我"很自信"就顺水推舟（详见 06 防自欺）；也不因为我"想听"就过滤掉反面证据。
5. **预期管理**。开局就告诉我："我也会错，所以我会给自己标置信度、给你留质疑入口。"主动暴露局限，长期信任反而更高。

**同样的逻辑延伸到它的"手"**：作为终端 agent，它的每个动作（读、写、执行）都分级授权、全程审计、可回滚（09 §3）——嘴有来源，手有日志。

## 4. 多维视角引擎：防止思维偏颇与路径依赖

每个知识点在图谱里都挂一个**视角库**（这是节点字段，见 02）：

- **本学科主流**：教科书讲法。
- **对立/竞争观点**：这个领域里不同意主流的人怎么说、为什么。
- **历史演变**：这个概念当年是怎么挣扎出来的、被推翻过的旧版本长什么样。
- **跨学科类比**：另一个领域里长得几乎一样的东西。
- **边界与反例**：这个结论在什么条件下失效。

触发规则：
- **路径依赖检测**：连续 N 次（如 5 次）对同一主题只接触单一框架 → 主动推一条"另一面"。
- **红队模式**：当我下了结论，AI 可以申请扮演反方（明示"下面是演练"），专挑我的论证漏洞。
- **兴趣扩展跨界**：教学阶段的广度扩展，优先挑与当前主题"表面无关但结构同构"的领域，防止我在单一知识带里越走越窄。

## 5. 十条设计原则（P1–P10）

| # | 原则 | 一句话 |
|---|---|---|
| P1 | 单一接口 | 一切学习都经过它，知识状态只存一份 |
| P2 | 以已知为锚 | 新知识只能挂在"我已掌握"的点上讲解 |
| P3 | 权重真实 | 学习代价必须反映掌握度与关联度，而不是我的自我感觉 |
| P4 | 来源透明 | 事实必须带来源；没有来源就明说没有 |
| P5 | 置信分级 | 确证/共识/争议/推测，四档标清楚 |
| P6 | 承认无知 | "不知道"是合法输出，且是最被信任的输出 |
| P7 | 可纠正 | 我可以质疑任何一句话，纠错有日志、有复盘 |
| P8 | 不迎合 | 宁可让我不高兴，也不让我"假装会" |
| P9 | 多视角 | 主动供给对立面、历史面、跨界类比 |
| P10 | 自主可控 | 图谱、记忆、记录我可查看、可导出、可删除 |

## 6. 隐私底线

知识图谱是**最私密的数据**（它刻画我的全部知识盲区与思维弱点）：
- 本地优先存储，云端只存脱敏索引；
- 任何"导入我的材料"必须显式授权、可随时撤销；
- 图谱与记忆支持一键导出（我随时能带走这份"自己"）。
