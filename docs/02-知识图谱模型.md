# 02 · 知识图谱模型

整个系统的数据核心是一张图，三类对象：**知识点（节点）、关联（边）、掌握度（状态）**。这张图同时回答两个问题："我脑中有什么"和"学新东西要走多远"。

## 1. 节点：知识点 K

一个知识点可以是一个概念、一条事实、一项技能或一个命题。它的全部字段：

| 字段 | 含义 | 示例（节点"导数"） |
|---|---|---|
| id | 唯一编号 | math.calc.derivative |
| 名称 | 术语 | 导数 |
| 一句话定义 | 供锚定用 | 函数在某点附近的变化率（瞬时斜率） |
| 类型 | 概念/事实/技能/命题 | 概念 |
| 难度 | 1–5 | 3 |
| 视角库 | 主流/对立/历史/跨学科/反例（见 01 §4） | 历史：牛顿-莱布尼茨之争…… |
| 来源[] | 可信出处 | 《托马斯微积分》第 2 章 等 |
| **掌握度 m** | **0–1，这是核心状态** | 0.1（还没学） |
| 掌握置信度 c | 对 m 的把握（样本不足时 m 不可靠） | 0.5 |
| 最近练习 | 上次生成式回忆测验时间 | — |
| 遗忘率 | 记忆衰减速度（个体化拟合） | 0.08/天 |

### 掌握度 m 的语义

- `m ∈ [0,1]`；**m ≥ 0.8 视为"已掌握"，构成"已知区 S"**。
- m 不是我口头声称"我会"，而是被**生成式回忆测验**验证过的结果（详见 06）：合上材料能讲出来、能做变式题，m 才升。
- m 随时间衰减（艾宾浩斯）：`m(t) = m₀ · e^(−t/τ)`，τ 按个体遗忘率拟合；长期不练，m 悄悄掉回未知区——图谱必须诚实反映这一点。
- m 的更新只认练习证据：生成式回忆对 → 升；错/蒙对 → 微升或不升；做错 → 降。（更新算法与感受类反馈的分工见 08 §1。）

## 2. 边：关联 E

| 字段 | 含义 | 示例 |
|---|---|---|
| (a, b) | 两个知识点 | (斜率, 导数) |
| 类型 | 前提 / 类比 / 构成 / 因果 / 对比 / 应用 | 类比+推广 |
| **关联度 r** | **0–1，越高越"顺路"** | 0.9（切线↔导数几乎一回事） |
| 方向 | 单向（前提）/ 双向 | 双向 |
| 依据 | r 的来源：教材同章节、论文引用、考试大纲先后 | 《托马斯微积分》2.1→2.2 |
| 说明 | 一句话解释这条边 | "导数就是切线的斜率" |

**关联度的来源优先级**：权威材料（教材目录、课程大纲、论文引用关系）> 用户自己建立的连接（"导数不就是瞬时的斜率吗"——这句话本身就是一条 r 很高的边）> LLM 估计（必须标注"待确认"，由用户/材料复核）。学习反馈也会持续回写 r：讲完当场测验成绩与"没听懂"的感受都会修正 r（08 §5）。

## 3. 权重：步进代价 c(a→b)

这是整个系统最重要的一个公式，它把"关联度"和"掌握度"折叠成一个数——**从 a 学 b 要付的代价**：

```
c(a→b) = ( 1 + λ·(1 − m_b) ) / r(a,b)     λ 默认取 3
```

读法：

- **b 已掌握（m_b ≥ 0.8）**：c ≈ 0.7/r —— 只花"建立连接"的力气。**这就是你说的"已有知识点之间的路径权重最小"**：复习、串联、打通旧知识几乎不花钱，而且是高杠杆的"顿悟"时刻。
- **b 全新（m_b ≈ 0）**：c ≈ 4/r —— 要付全额学习代价。**这就是"新知识点权值较大"**。
- **r 高** → 分母大 → 便宜（关联紧密、直接能懂）；**r 低** → 贵。
- **连续新点惩罚**：若 b 只能通过另一个新点 c 中转（c 自己也没掌握），理解 b 时要同时悬空两个概念。可选修正：路径中每个"前置点未掌握"的新点，代价再乘 δ（默认 1.5）。这样"借其他新知识点中转"自然比"直接挂已知点"贵——正是你说的"权衡出最优路径"。

**练习巩固减小权重的数学含义**：练习 → m_b 上升 → (1−m_b) 下降 → c 下降。同一条路径，随着掌握加深，代价逐步趋近纯连接价（≈0.7/r）。"逐步减小权重"不是比喻，是公式的直接结果（03 §5 有演示）。

## 4. 用户的图谱状态（三个区）

- **已知区 S**：m ≥ 0.8 的点——路径的起点，讲解的锚。
- **半知区**：0.3 ≤ m < 0.8——"见过但没会"，是练习调度的重点对象。
- **未知区**：m < 0.3 或图谱里还没有的点。
- 另有**兴趣向量** i(k) ∈ [0,1]：每个主题我的兴趣值，用于路径偏好与广度扩展。兴趣会漂移，由感受反馈持续更新（08 §4）。

## 5. 最小示例（也是 prototype 里的测试数据）

```json
{
  "nodes": [
    {"id": "斜率",  "m": 0.80},
    {"id": "函数",  "m": 0.85},
    {"id": "切线",  "m": 0.30},
    {"id": "极限",  "m": 0.10},
    {"id": "连续",  "m": 0.15},
    {"id": "导数",  "m": 0.10}
  ],
  "edges": [
    {"a": "斜率", "b": "切线", "r": 0.90, "type": "类比"},
    {"a": "切线", "b": "导数", "r": 0.90, "type": "前提"},
    {"a": "斜率", "b": "导数", "r": 0.45, "type": "类比"},
    {"a": "函数", "b": "极限", "r": 0.70, "type": "前提"},
    {"a": "极限", "b": "连续", "r": 0.90, "type": "前提"},
    {"a": "连续", "b": "导数", "r": 0.75, "type": "前提"}
  ]
}
```

已知区 = {斜率, 函数}，目标 = 导数。三条候选路径：斜率→导数（直连但 r 低）、斜率→切线→导数（每跳都高关联、且新点只挂一个）、函数→极限→连续→导数（连续两个新点中转）。哪条是"权重最小"，由 03 的算法回答。

## 6. 图谱从哪来

1. **我的自述**（探寻阶段，04 §1）：我讲、AI 提炼成点与边，逐条让我确认——这是"已知区"最可信的来源。
2. **我的已有材料**（授权后）：笔记、收藏、课程大纲 → 抽点、抽 r（接入管线见 09 §5）。
3. **权威结构化资料**：教材目录、教学大纲、论文引用图 → 抽"标准图谱"。
4. **LLM 估计**：只做候选，**必须打"待确认"标，由我或材料复核后才入图**。

图谱不是一次建成的：每次教学、每次练习、每次我随口说的类比（"这不就是……吗"），都在增点、加边、更新 m 与 r——**图谱和我一起成长**。
