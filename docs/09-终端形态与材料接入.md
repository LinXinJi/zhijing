# 09 · 终端 Agent 形态与材料接入

## 1. 定位：教学 AI 是一个住在终端里的 Agent

- 它不是一个网页应用，也不只是一个会聊天的 CLI 程序——它是**能行动的 agent**：读文件、写文件、执行命令、维护自己的状态（图谱/调度/记忆落盘）。
- "唯一接口"（01）+ "唯一工作台"（我的终端）：学习发生在**我已经在用的地方**（如 `F:\个人成长\系统学习\`），产物就地落在我的目录里。
- **行动即教学**：讲代码时当场建文件、跑起来验证（呼应 05 的生成约束）；讲完一课把图谱与报告写进我的目录。

## 2. Agent 的工具箱（它能做什么）

| 工具 | 用途 | 教学场景举例 |
|---|---|---|
| read_file / write_file | 读写文件 | 读我的笔记做锚；写图谱导出、学习报告 |
| search | 在我的材料里检索 | 讲解前搜"我笔记里怎么记的"（RAG，05 §3） |
| run_command | 执行命令 | 跑示例代码验证、跑练习脚本、mmdc 渲染图谱 |
| web_fetch | 联网查证（受限） | L3/L4 事实核查（05 §2） |
| graph | 图谱操作 | 加点、加边、查路径、更新 m/r（02/03） |
| graph_ops（`tools/graph_ops.py`） | 确定性计算 | 路径规划、m/间隔更新、校准统计、图谱导出——LLM 只讲解、不口算 |
| diagram-design（pi skill，用户已安装） | 出图 | 路径图/概念图/终局图谱/进度图的美观渲染（SVG/PNG）；**默认自动使用，无需用户要求**；图上数据必须取自 graph_ops 输出 |
| quiz / review | 练习引擎 | 生成式回忆测验、间隔重复（06） |
| state | 状态维护 | 会话、调度器、记忆、纠错日志落盘 |

## 3. 权限与审计：信任从"嘴"延伸到"手"

Agent 能执行命令 ⇒ 必须受控。**分层权限（默认最小权限）**：
1. **只读**（默认）：读我的笔记、列目录、查图谱；
2. **写工作区**：生成图谱/报告/导出——写我的目录前先征得同意；
3. **执行命令**：沙箱内运行；危险操作（删除、改系统配置、联网）逐个确认。

配套机制：
- **行动审计日志**：每个动作（读了什么、写了什么、跑了什么命令）一行记录，可查、可回放；
- **产物版本化**：导出的图谱/报告可回滚；**我的笔记它从不擅自修改**；
- 与 05 同构：**嘴说的话有来源，手做的事有日志**——这是我敢把"唯一接口"交给它的前提。

## 4. 终端里的互动：对话 + 命令 + 行动

| 命令 | 作用 | 命令 | 作用 |
|---|---|---|---|
| `/plan` | 规划最优路径（确认后自动出规划图） | `/demo` | 演示学习方案 |
| `/teach` | 下一课（受门禁约束） | `/quiz` | 生成式回忆测验 |
| `/review` | 间隔复习 | `/feel` | 30 秒感受收口（08） |
| `/calibrate` | 校准面板（08 §6） | `/graph` | 看当前知识图谱 |
| `/progress` | 学习进度面板（科学指标） | `/source` | 出示来源（05） |
| `/import` | 导入我的笔记/材料 | `/doubt` | 质疑并纠错（05） |
| `/undo` | 回滚最近一次事件 | `/finish` | 学完归档到 已经学完 |
| `/graduate` | 封版终局图谱（10，自动附精美图） | `/help` | 全部命令 |

- 普通输入 = 对话；`/` 开头 = 命令；**工具调用在对话流中自然发生**，每次行动一行审计可见；
- 长输出分页；状态栏常驻"下一步建议"（如 `[/review] 3 个点该复习了`）；
- Ctrl+C 随时中断，状态已持久化，下次继续。

## 5. 材料接入：我的笔记 + 收集的材料

材料是双料输入：**知识图谱的来源**（02 §6）和**教学的可信语料**（05 §3）。我的笔记还是"熟悉性"的载体——讲解优先从我自己写过的话出发（01 §2）。

**接入流程（`/import`）**
1. 指向目录/文件（如 `F:\个人成长\系统学习\Python\`）或粘贴 URL 收藏；
2. 解析 → 切块 → 本地索引（全文 + 向量）；
3. 抽点抽边：笔记标题、大纲、链接 → 候选知识点与关联，**逐条让我确认**后才入图；
4. **来源锚定**：每个知识点挂回"出处文件 + 位置"——讲课时引用材料能 `/source` 看到原文片段。

**格式支持**：Markdown（我的笔记，优先支持）、txt、HTML、PDF（抽取文本）、URL 快照。非文本格式统一转 Markdown 中间格式。

**材料分层（信任不等同）**
- **我的笔记** = 最高信任 + 熟悉性来源（讲课优先锚定："你在《xxx.md》里写过……"）；
- **收集材料** = 按来源权威度加权：官方文档/教材 > 权威教程 > 博客/论坛（对应 05 的五级分级）；
- 冲突时以我的材料为锚讨论，不静默覆盖（05 §3.4）。

**增量与隐私**：文件更新 → `/import` 增量同步，图谱标"材料已变更"；材料、索引、图谱全部本地优先（01 §6），索引格式开放可迁移。

## 6. 四阶段在 Agent 形态下

- **探寻**：对话式访谈与读我笔记并行——我边聊，它边扫描我的目录、把笔记抽成候选点；
- **计划**：`/plan` 输出 ASCII 路径：`斜率 ─(r=0.9, 3.44)→ 切线 ─(r=0.9, 4.11)→ 导数`，附总代价与理由；
- **演示**：`/demo` 全文渲染路径 + 备选对比表 + 每一跳的"为什么"，可导出 Mermaid/HTML；
- **教学**：七步课在对话流里执行，讲解与行动穿插（当场跑代码、开测验、往图谱里写连接）；`/quiz`、`/review`、`/feel` 命令化收口（08）；
- **校准**：`/calibrate` 输出面板表格（信心 vs 实际、自欺热点榜）。

## 7. 技术要点

- **事件循环**：感知（对话 + 状态）→ 思考（LLM + 图谱）→ 行动（工具）→ 反馈（审计 + 结果）；
- **权限层设在事件循环入口**：每次工具调用先过权限判定（§3）；
- 全状态本地持久化：图谱、调度、记忆、审计日志都在我的目录里，开放格式（01 §6）；
- 完整对话历史与数据落盘本地，我可导出、可删除。
