# 07 · 实施路线图（终端优先）

## P0 纸面验证（1–2 周，不写代码）

- 挑一个小主题，用真实对话手工走一遍四阶段：手工建 10–20 点小图谱，手工算路径；
- 验证的核心问题："这条路真的比我自学顺吗？探寻是否让我觉得被理解？演示是否让我信服？"
- 同时记录：我在哪些环节想放弃、哪些问题觉得多余——这就是 08 的第一批感受反馈。

## P1 MVP（2–4 周）：终端里走通一个主题

- **界面**：终端 Agent（对话 + `/` 命令 + 行动：文件读写/命令执行，带权限层与审计日志，见 09）；会话状态本地持久化；
- **图谱**：JSON 存储 + 对话/手工建图；Dijkstra 最优路径（`prototype/demo_path.py` 已先行验证）；
- **练习**：生成式回忆测验 + 简化 SM-2 调度；成绩回写 m（08 §5）；
- **反馈**：每课 30 秒感受收口（`/feel`）+ 成绩自动记录 → 校准 m、r（08）；
- **可靠性**：五级事实标注 + 来源字段 + `/source` 出示来源（05）；
- **图谱导出**：`/graph` 实时看 ASCII 图谱，可导出 Mermaid；
- **验收**：单主题完整走通四阶段；路径总代价曲线可见下降；能导出第一张"阶段性图谱"。

## P2 材料与规划（1–2 月）

- **材料接入管线**：`/import` 我的笔记与收集材料（解析/切块/本地索引/抽点确认，09 §5）；
- **规划升级**：Top-k 备选、兴趣加权、动态重规划（练习后自动重算，03 §5）；
- **可视化**：路径 ASCII 渲染 + Mermaid/HTML 导出；校准面板（信心 vs 实际，08 §6）；
- **门禁与调度**：阶段门禁、交错练习、个体遗忘率 τ 拟合；
- **终局图谱**：`/graduate` 生成学习过程图谱 + Markdown 报告 + JSON/GraphML（10）。

## P3 个性化与可靠性（1–2 月）

- **长期记忆与画像**：风格、示例偏好、节奏——由感受反馈持续校准（08 §4）；
- **多视角引擎**：视角库 + 路径依赖检测 + 红队模式（01 §4）；
- **RAG**：材料库检索增强讲解；纠错日志与来源质量分（05 §6）；
- **动力信号**：情绪/疲劳/兴趣漂移入校准（08）。

## P4 打磨

- 多模态（图形/语音）、数据导出与隐私本地化、跨主题图谱联通（`系统学习` 各目录逐步接入）、与 shell 生态集成（别名/补全）、成本优化。

## 技术选型建议

- **终端 Agent 框架**：事件循环 + 工具层 + 权限层；Python（rich / textual，与原型同生态）起步，性能瓶颈再考虑 Rust（ratatui）；
- **LLM**：API 接入（模型可替换）；**向量库**：本地优先（如 sqlite-vec / lance）；
- **图**：小规模 JSON + NetworkX（与原型一致），规模大了再 Neo4j；
- **调度**：SM-2 起步，之后个体 τ 拟合；
- **导出**：Mermaid / GraphML / Markdown——全开放格式，不锁死。

## 成功度量

| 指标 | 目标 |
|---|---|
| 掌握速度 | 同样目标，比自学路径缩短的时间 |
| 校准误差 | 信心 vs 实际正确率的差，持续收窄 |
| 路径合理率 | 我认可"每一步都顺路"的比例 |
| 幻觉/纠错率 | 被复核证伪率持续下降 |
| 反馈覆盖率 | 每课感受收口完成率 ≥ 90% |
| 材料利用率 | 我的笔记/收集材料被讲解引用的比例 |
| 留存 | 连续学习周数与阶段完成率 |

## 风险与对策

- 图谱质量依赖 LLM → 全部打"待确认"标，人工复核（02 §2）；
- 隐私（图谱 = 我的思维地图）→ 本地优先、可导出、可删除（01 §6）；
- 单点依赖 → 可靠性层 + 定期"无 AI 对照测验"（纯纸笔自测）；
- 感受数据的主观性 → 只校准"怎么教"，不校准"学会没有"（08 §1）；
- 材料格式杂 → 统一转 Markdown 中间格式再索引（09 §5）；
- 终端渲染能力有限 → ASCII 优先，复杂图导出浏览器看（09 §4）。
