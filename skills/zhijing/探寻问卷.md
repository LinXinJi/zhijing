# 探寻问卷（一阶段·探寻 的标准动作）

目的：从宽到细把用户的已知区标定进 `graph.json`，并校准"以为会 vs 真会"。
原则：**口头"我会"不采信**——每一个"会"都要用生成式回忆验证（不提示、让用户讲出来）。

## 宽：领域层（5–10 分钟）

1. 这个主题你以前学过吗？什么时候、什么场景下？
2. 现在还记得哪几个词/章节名？（只列词，不解释——防止被词面提示）
3. 工作/学习里实际用过吗？最近一次是什么时候、用来做什么？

## 中：子主题打标（10 分钟）

- 列出候选子主题清单（来源：教材目录/大纲、`/import` 抽出的标题、LLM 候选），
  让用户逐项打标：**会 / 见过 / 不会**。
- 标完把"会/见过"的点记入 graph.json（暂用初始 m 占位），"不会"的待教学阶段再入。

## 细：逐点探测与 m 初始化（每个"会/见过"的点）

- 对"会"的点做生成式回忆测试："合上材料，用自己的话讲一遍 X"，再给一道变式题：
  - 讲得出、变式题对 → `m = 0.80`（直接入已知区 S）
  - 讲得出但犹豫 → `m = 0.60`
  - 讲不出但"眼熟" → `m = 0.30`
  - 完全没印象 → `m = 0.10`
- "见过" → `m = 0.30`；"不会" → 不入图或 `m = 0.10` 待教。
- 每次探测把结果写进节点 `history`（evt: explore），并追加 `meta.process`（evt: explore）。

## 收尾

- 兴趣评分（0–100）写入 `meta.interest`；负荷基线（每日可投入时间、最佳学习时段）记入画像；
- 校准基线：把"自评会 vs 实测会"的差距记入校准面板（08 §5）——它是后续防自欺的参照点；
- **向我复述已知区，让我确认**："你的已知区是这些，对吗？"——确认过的地图才进入计划阶段。

## 防自欺要点

- 不提示、不追问暗示；用户说"我会"时只问"那你自己讲一遍"；
- 蒙对的、想很久才对的，都按"犹豫"记，不按"对"记；
- 探寻阶段说"不会"零成本——明确告诉用户，降低防御心理。
